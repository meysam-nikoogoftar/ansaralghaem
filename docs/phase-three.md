# فاز سه — تکمیل مهاجرت خانه، فروشگاه و پیگیری

مسیرهای `/`، `/shop`، `/shop/[id]` و `/track` در Next هستند و در shared/migration-routes.json ثبت شده‌اند. لینک‌های حساب و مدیریت از مرز Next/Vite عبور می‌کنند. import صفحات فاز سه از App قدیمی حذف شده؛ فایل‌های قدیمی فقط برای سابقه و تطبیق نگه داشته شده‌اند.

## پیاده‌سازی

- خانه: داده‌های عمومی در سرور، موازی و با revalidate=60 دریافت و با Zod محدود می‌شوند. اسلایدر، swipe، توقف حرکت هنگام فوکوس/reduced-motion، شمارش معکوس، آمار، سفر، کیف پول خصوصی، اطلاعیه، گالری دسته‌بندی‌شده و lightbox، اخبار، مشارکت، نقل‌قول و CTAها حفظ شده‌اند. ثابت‌ها و fallbackهای محتوایی نسخه قبلی حفظ شده‌اند.
- تفکیک کامپوننت‌ها: Home، HeroSlider، Countdown، HomeGallery، ShrineAnimation و موتور shrine-webgl؛ همه TypeScript هستند. شمارش معکوس فقط کامپوننت خودش را هر ثانیه رندر می‌کند. انواع مشترک در types/home.ts و types/shrine.ts قرار دارند؛ از any و ts-ignore استفاده نشده است.
- حرم: SVG ثابت در SSR نمایش داده می‌شود. موتور Three.js فقط در دید و روی دستگاه مناسب و بدون save-data/reduced-motion دریافت می‌شود. با خروج از دید یا مخفی‌شدن سند حرکت متوقف و هنگام unmount منابع آزاد می‌شوند. افت فریم، شکست WebGL یا GPU نرم‌افزاری به SVG بازمی‌گردند.
- فروشگاه: فهرست و جزئیات SSR، جست‌وجو و دسته‌بندی GET، قیمت/تخفیف/موجودی، 404 محصول، خرید پس از ورود و بازگشت به محصول، فرم تعداد/آدرس/کد پستی و رسید سفارش. اطلاعات فرم هویتی در URL ذخیره نمی‌شوند. تصاویر مجاز با next/image و sizes نمایش داده می‌شوند؛ تصویر اول اسلایدر priority دارد.
- امنیت خرید: قیمت فقط سمت سرور محاسبه می‌شود. تعداد مثبت، کد پستی و طول آدرس اعتبارسنجی می‌شوند. موجودی و سفارش در تراکنش و با select_for_update تغییر می‌کنند؛ محصول منتشرنشده قابل سفارش نیست. مرورگر قفل ارسال دارد و پس از رسید فرم غیرفعال می‌شود. پس از خطای ارتباط، سفارش خودکار تکرار نمی‌شود.
- پیگیری: POST با CSRF و محدودیت نرخ مشترک دیتابیس؛ GET هویتی حذف شده است. پاسخ فقط نام، عنوان سفر، کد و وضعیت‌ها را برمی‌گرداند. اطلاعات مالی، موبایل، کد ملی و همراهان از پاسخ عمومی حذف شده‌اند. صفحه noindex و robots مسدود است؛ API private,no-store است.
- SEO: عنوان، توضیح و canonical، HTML اولیه قابل خواندن، sitemap خانه/فروشگاه/محصولات و Product/Offer JSON-LD با قیمت IRR و وضعیت موجودی. لینک و تصویر دریافتی از API قبل از مصرف محدود می‌شوند؛ JSON-LD escape و nonce دارد.

## شواهد اجرا

- build تولید Next و Vite، typecheck، ۸ تست واحد Next، ۵ تست اپ قدیمی و ۱۰ تست Django برای نشست، سفارش و پیگیری پاس شدند.
- `npm run test:e2e` با Django واقعی، دیتابیس موقت، Next production و Vite ایزوله پاس شد: SSR خصوصی، CSRF/Origin، ابطال نشست، خرید واقعی آزمایشی، بازگشت پس از ورود، مرز پروفایل Vite، محصول ناموجود/404، جست‌وجوی خالی، گالری/lightbox، پیگیری موفق/ناموجود/503، canonical و JSON-LD و noindex.
- چهار مسیر در عرض 390px بدون overflow افقی و بدون pageerror بررسی شدند. نمونه دسکتاپ 1440px، reduced-motion و حرکت معمول نیز بررسی شد. تصاویر در phase-three-baseline قرار دارند.
- نمونه سرعت از Chromium محلی، production build، دیتابیس fixture و cache گرم در [results.json](phase-three-baseline/results.json) ثبت شده است: TTFB، DOMContentLoaded، آخرین LCP مشاهده‌شده و CLS. این اندازه‌گیری کوتاه آزمایشگاهی است؛ ادعای Core Web Vitals واقعی کاربران یا سرعت اینترنت تولید نیست. نتایج باید پس از استقرار با داده واقعی پایش شوند.
- `npm audit` پس از رفع سه وابستگی انتقالی: صفر آسیب‌پذیری گزارش‌شده.

دستور تست: از frontend-next، `npm run test:e2e`؛ برای مرورگر CI، `npx playwright install --with-deps chromium`. Python محیط تست را می‌توان با SECURITY_TEST_PYTHON تعیین کرد؛ مرورگر موجود با PLAYWRIGHT_CHROMIUM_EXECUTABLE قابل انتخاب است. داده fixture، media و پردازش‌های تست موقت هستند و حساب واقعی تغییر نمی‌کند.

محدودیت محیط: مسیر WebGL سخت‌افزاری به GPU واقعی نیاز دارد؛ در Chromium نرم‌افزاری این محیط fallback SVG و انیمیشن آن تست شده است. استقرار عمومی و سنجش میدانی خارج از این اجرای محلی هستند.
